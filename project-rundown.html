  • Effects: Glowing box-shadow (12px and 24px spread)

  • Visual: SVG circle (48px diameter, 10px stroke) with "DIMOKOL • DIMOKOL •" text
  • Behavior:

    • Uses mix-blend-mode: difference (via parent) for color adaptation

  • Hover State:

    • Scales to 1.15x

Cursor Trail

  • Visual: 400px radial gradient glow following cursor
  • Behavior:
    • Slower easing (0.08) than main cursor
    • Uses mix-blend-mode: difference
    • White gradient that should invert on backgrounds

Idle Particles (Orbital)

  • Trigger: After 2 seconds of no movement
  • Visual: 15 white dots (4px each) with mix-blend-mode: difference
  • Behavior:
    • Circle formation around cursor (35px radius)
    • Rotation with subtle speed variation (sine wave)
    • Sequential fade-in
    • Sequential fade-out when movement resumes

Edge Idle Animation

  • Trigger: Cursor idle at screen edges (within 5px)
  • Corner Mode: Quarter-circle burst pattern, pulsing waves
  • Side Mode: Ray emission in 120° arc away from edge
  • Visual: Same 15 particles with wave-based opacity/distance

Trail Dots

  • Trigger: When cursor moves with speed > 1
  • Spawn Rate: Every 30ms
  • Visual: 4px white dots with mix-blend-mode: difference
  • Lifecycle:
    • Visible for 600ms
    • Fades out over 300ms
    • Removes idle dots sequentially as trail spawns

Click Ripple

  • Trigger: On mousedown
  • Visual: Expanding circle border (0→80px over 600ms)
  • Behavior: Orange color, uses mix-blend-mode: difference

Magnetic Attraction

  • Targets: Links, buttons, feature cards, gallery items, form inputs, [data-magnetic]
  • Behavior:
    • Distance-based falloff (200px max, 50px min)
    • Quadratic strength scaling
    • Pulls cursor toward element center
    • 0.35 strength when very close (< 50px)
  • Element Distortion:
    • Elements translate 0.2x toward cursor position
    • Smooth reset on mouse leave (0.5s cubic-bezier)

Cursor States

  • Default: Normal following
  • Hover: Scale, faster rotation, glow
  • Click: Scale down to 0.8, add hover class
